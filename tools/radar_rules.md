# Desk Picker 규칙

[블로그]
- 블로그 이름: Desk Picker (한글 표기: 데스크피커). 영문은 띄어쓰기·대소문자를 항상 'Desk Picker'로.
- 주제: 책상과 그 주변에서 쓰는 모든 물건(책상꾸미기·정리 / 조명 / 충전·전원 / 음향 / 입력 / 몸편한것 / 겨울제철).

[공통]
- 맨 위 대가성 문구: "이 포스팅은 네이버 쇼핑커넥트 활동의 일환으로, 판매 시 수수료를 제공받습니다."
- 써보지 않은 제품이다. "후기", "써보니", "직접 사용", "내돈내산" 금지. 상품 페이지의 사실, 구매자 후기에서 반복되는 의견("구매자 후기에서 ~라는 말이 많았어요"처럼 요약), 고르는 기준으로 쓴다. 사용자가 실제로 쓰는 제품은 따로 알려 주며, 그때만 경험 표현을 쓴다.
- 금지 표현: 최고, 무조건, 100%, 완벽, 강력 추천, 1위(출처 없는 순위).
- 가격은 "작성일 기준 약 ○○원(변동 가능)".
- 모든 숫자는 facts.json 에 출처가 있어야 한다. 모르면 쓰지 않는다. 안전·건강 효과(화상 없음, 전자파 0 등)는 상품 페이지에 인증 표시가 있을 때만 "~로 표시돼 있어요"로 쓴다.
- 말투: ~요체, 짧은 문장, 과장 없이.
- 이미지는 전부 1080x1080. 상세페이지 이미지는 글당 1~2장.
- 상품 카드 자리는 [상품카드: 상품명], 같은 날 다른 글로 갈 링크 자리는 [내부링크: 글 제목] 으로 표시(발행 때 직접 넣음).
- "직접 써 보고 쓴 글은 아니에요", "상품 페이지와 구매자 후기를 바탕으로 정리했어요"처럼 글의 작성 방식을 밝히는 문장은 쓰지 않는다. 써봤다고도, 안 써봤다고도 말하지 않는다.
- 써본 것처럼 보이는 표현(써보니, 직접 사용, 제가 써본, ○일 사용, 실사용)은 계속 금지.
- 정보의 출처는 문장 안에서 자연스럽게 드러낸다(예: "상품 페이지에는 ~로 표시돼 있어요", "구매자 후기에서 ~라는 말이 많았어요").

[틀 A 고르는 법] 1,800~2,500자, 소제목 5~7개. 필요한 상황 → 고를 때 볼 기준 3~5개(기준마다 왜 중요한지) → 비교표(제품 4~5개 × 기준) → 상황별 추천(예: 사무실 책상 밑, 원룸, 전기요금이 걱정될 때) → 이런 경우는 피하기 → 정리. 상품 카드 2~3개.

[틀 B 모델명] 1,300~1,800자, 소제목 4~6개. 한 줄 결론(누구에게 맞는지) → 기본 정보표(가격·크기·핵심 사양) → 구매자 후기에서 반복된 장점 → 아쉬운 점 → 비슷한 대안 1~2개와 차이 → 맞는 분 / 안 맞는 분. 상품 카드 1개.

[반복 피하기] 소제목 문구와 순서를 글마다 바꾼다. 같은 날 글끼리 같은 소제목을 쓰지 않는다. 첫 문장은 상황 묘사 / 질문 / 결론 중 돌아가며 쓴다.

[제목]
- 40자 이내. 키워드는 글자 그대로 제목 맨 앞 15자 안에 넣는다.
- 틀 A(고르는 법 글): "키워드 + 끝맺음". 끝맺음 6가지를 돌려 쓴다. 제목마다 아래 6가지 중 하나가 분명히 보여야 한다.
  ① 추천 — 예: 듀얼 모니터 받침대 추천, 책상 폭별로 고른 3가지
  ② 고르는 법·기준 — 예: 발난로 고르는 법, 사무실 책상 밑에 둘 때 볼 기준
  ③ 비교·차이 — 예: 보조배터리 10000 vs 20000, 차이와 선택 기준
  ④ 사기 전 확인할 점 — 예: 책상 정리함, 사기 전 확인할 점
  ⑤ 답이 보이는 질문 — 예: 발받침대, 어느 높이가 오래 앉기 편할까?
  ⑥ 숫자 — 예: 무선 마우스 고를 때 볼 3가지
- 틀 B(모델명 글): "브랜드 모델명 + 제품 종류 + 궁금한 점"이 기본(예: 브라운 BC02XW 탁상시계, 크기·소리·가격 정리). "살 만할까", "이런 분께 맞아요" 끝맺음도 쓴다.
- '추천'은 써도 된다. 뜻은 '사양·구매자 평가·쓰는 상황을 알아보고 고른 제품을 권한다'이다. 직접 써본 것처럼 경험을 꾸미는 말(직접, 제가, 써본, 솔직, 찐, 인생 등)과 함께 쓰지 않는다.
- 제목 금지 단어(원고도 같음): 후기, 내돈내산, 써보니, 사용기, 실사용, 직접 써본, 최고, 무조건, 100%, 완벽, 강력 추천, 1위. 효과를 단정하는 말도 넣지 않는다.
- 한 주 분산: 틀 A 14편 중 같은 끝맺음은 최대 4편, '고르는 법'이 들어간 제목은 최대 3편, 같은 날 올라가는 틀 A 2편은 서로 다른 끝맺음으로 한다.

[표지] 1080x1080. 제품 사진 위에 제목 핵심 2줄(한 줄 12자 이내, 굵게, 흰 글자)과 작은 범주 표시(예: 책상 겨울템, 책상 정리템). 강조색은 #F2B544 하나로 고정. 배치 3가지를 돌아가며 쓴다: ① 아래쪽 1/3 반투명 띠 ② 왼쪽 위 글자 + 얇은 테두리 ③ 가운데 제품 + 위아래 글자. 오른쪽 아래에 작은 글씨로 'Desk Picker'(흰색, 투명도 70%, Pretendard). 제품 사진을 늘리거나 없는 기능을 그려 넣지 않는다.
