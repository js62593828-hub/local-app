# 사실 확인 메모: B 월세 세액공제 (조건·경정청구·한도)

확인일 2026-11-19. 검색 4회 + 열기 5회 사용(상한 12회 이내). 표기: 열어서 확인함 / ⚠ 검색 요약만 또는 못 확인.
국세청 월세 안내 본문(아래 NTS)은 "2024.12.31 기준" 표기 페이지입니다. 2026-01-23 화성세무서 보도자료로 공제율·한도가 그대로임을 교차 확인했습니다.

## 1. 총급여 기준과 공제율
- 사실: 총급여 8,000만 원 이하 근로자(종합소득금액 7,000만 원 이하)가 대상. 총급여 5,500만 원 이하(종합소득금액 4,500만 원 이하)는 월세의 17%, 5,500만 원 초과~8,000만 원 이하는 15%.
- 숫자: 5,500만 / 8,000만, 17% / 15%
- 출처: https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=40613&cntntsId=239025 · 열어서 확인함 (기준일 2024.12.31 표기)
- 교차: https://j.nts.go.kr/hwaseong/na/ntt/selectNttInfo.do?mi=8896&bbsId=1028&nttSn=1348212 (2026.1.23 보도자료) · 열어서 확인함. 17%·15% 확인. 이 글에는 "8,000만 원 확대"를 따로 설명하지 않고 "현재 8,000만 원 이하"로만 적혀 있음.
- 주의: 7,000만 원 구간은 옛 기준. 글에 쓰지 말 것. 8,000만 원 이하로 확대된 시점(귀속연도)은 ⚠ 공식 문서로 못 확인(검색 요약에서는 "7,000만 → 8,000만 확대"라고만 나옴).
- 2026년 귀속 추가 개정 여부: 올해(2026년 귀속 연말정산) 기준을 바꾸는 개정은 못 찾음 ⚠ (법령 조문 원문은 열지 못함).

## 2. 월세 한도
- 사실: 공제 대상 월세액은 연 1,000만 원까지. 최대 공제액 17%면 170만 원, 15%면 150만 원.
- 출처: 위 NTS 페이지와 화성세무서 보도자료 · 열어서 확인함
- 개정안: 2026.8.3 정부 세제개편안에 한도 1,200만 원 상향(청년 특례 포함)이 있으나, 2027년 지급분부터 적용 전제의 정부안이고 국회 통과 여부 못 확인 ⚠ (검색 요약만). 올해 연말정산(2026년 귀속)에는 해당 없음. 글에는 "현재 1,000만 원"으로 쓰고, 개정안은 쓰더라도 "논의 중"으로만.

## 3. 무주택 세대주·세대원 요건
- 사실: 무주택 세대의 세대주(세대주가 주택 관련 공제를 받지 않은 경우 세대원도 가능). 본인 또는 기본공제대상자 명의로 임차.
- 출처: NTS 월세액 세액공제 조건 페이지 · 열어서 확인함. 세대원 조건 문구는 화성세무서 보도자료에서도 확인함.
- 배우자 추가 공제(2025.12.23 개정으로 제95조의2 제2항 신설): ⚠ 검색 요약만. 글에 쓰려면 법령 원문 확인 필요.
- 무주택 판정 세부(주택 보유 시점, 오피스텔 등): ⚠ 못 확인.

## 4. 주택 기준
- 사실: 국민주택규모(전용 85㎡) 이하 또는 기준시가 4억 원 이하 주택. 주거용 오피스텔·고시원 포함.
- 출처: NTS 월세액 세액공제 조건 페이지 · 열어서 확인함
- 참고: "자녀 3명 이상이면 면적 100㎡" 개정(2026.2.27)은 ⚠ 검색 요약만. 쓰지 않는 것을 권함.
- 주의: 두 기준 중 하나만 충족해도 되는지, 둘 다 필요한지는 NTS 페이지의 "또는" 표기를 따랐음. 시행령 원문은 ⚠ 못 열어 봄(law.go.kr 조문 본문은 열리지 않음).

## 5. 임대차계약서 명의·전입
- 사실: 임대차계약서 주소와 주민등록등본(표) 주소가 같아야 함(전입신고 필요). 전입신고를 못 했으면 월세 세액공제를 받을 수 없음. 대신 월세 현금영수증 발급 신청 후 신용카드 등 소득공제는 가능.
- 출처: 홈택스 FAQ https://teer.hometax.go.kr/home.do?faqId=134391&loginId=&mode=getFaq_view&url=pub%2FgetFaq_view&viewYn=Y · 열어서 확인함. NTS 페이지에서도 확인.
- 현금영수증과 세액공제는 중복 불가(국세청 Q&A에서 월세 현금영수증은 카드 사용액 화면에 안 보이게 처리) https://call.nts.go.kr/call/qna/selectHomeQnaInfo.do?mi=3555 · 열어서 확인함. "둘 중 하나 선택" 문구 자체는 ⚠ 검색 요약만.

## 6. 증빙
- 사실: 주민등록표등본, 임대차계약증서 사본, 계좌이체 영수증 또는 무통장입금증 등 월세 지급 증빙. 연말정산 때 회사에 제출.
- 출처: NTS 월세액 세액공제 조건 페이지 · 열어서 확인함
- 계약서 명시 계좌가 아닌 계좌로 보내도 지급 사실이 확인되면 가능, 계약서 분실 시 임대인 확인서: ⚠ 검색 요약만(홈택스 상담 답변이라 하나 열지 못함).

## 7. 경정청구 (연말정산 때 빠뜨린 경우)
- 기한 5년: 연말정산 납부기한 경과일부터 5년 이내(국세기본법 제45조의2 근거). ⚠ 검색 요약만. 열어 본 공식 페이지(국세청 Q&A, 홈택스 FAQ)에는 5년 문구가 없었음. 글에 쓰기 전 국세청 경정청구 안내 한 번 더 확인 필요.
- 홈택스 신청 순서: 검색 요약은 "홈택스 > 세금신고 > 종합소득세 > 근로소득자신고서 > 경정청구작성"(2019년 매뉴얼 PDF 근거) ⚠ 현재 화면 이름과 다를 수 있음. 메뉴 이름은 직접 확인 못 함.
- 2025년 귀속 근로소득 경정청구 서비스는 2026년 7월경 오픈 안내(국세청 Q&A) · 열어서 확인함. 올해 연말정산(2026년 귀속)분 경정청구는 내년에 가능하다는 뜻.
- 제출 서류: 경정청구서, 정정분 원천징수영수증, 정정분 소득공제신고서, 증빙 ⚠ 검색 요약만.
- 환급은 실제 낸 소득세가 있어야 가능(낸 세금보다 더 돌려받지 못함): ⚠ 검색 요약만.
- 주의: 보도자료 속 "홈택스 주택 임차료(월세) 현금영수증 발급 신청"은 경정청구와 다른 절차(현금영수증 소득공제용). 섞어 쓰지 말 것.

## 8. 한도 초과 계산에 필요한 숫자
- 1,000만 원 ÷ 12개월 = 83.33만 원. 월세가 월 83만 원이면 연 996만 원으로 한도 안, 월 84만 원부터 연 1,008만 원이라 한도 초과. 엄밀히는 월 83.4만 원부터 초과(제목의 "83만 원 넘는" 표현은 맞음).
- 연 1,000만 원 초과분은 공제 대상이 아님. 예: 월 90만 원 = 연 1,080만 원이면 1,000만 원까지만 계산, 80만 원은 제외. 17%면 170만 원, 15%면 150만 원(최대치 출처: 위 확인된 NTS 자료).
- 위 계산은 단순 산수이고 임차일수 일할 계산 규정은 ⚠ 법령 원문 못 확인(1년 전체 거주 가정으로만 쓸 것).

## ⚠ 개수 요약
공식 문서로 못 확인한 항목: 8,000만 확대 시점, 2026년 귀속 추가 개정 없음, 배우자 추가 공제, 무주택 세부, 100㎡ 개정, 시행령 원문, 계약서 계좌·분실 예외, 경정청구 5년, 홈택스 메뉴 경로, 제출 서류, 환급 조건, 한도 1,200만 원 개정안 처리, 일할 계산 = 13개

## 추정 (확인 아님, 맨 아래 분리)
- 올해 연말정산에서 월세 공제가 빠졌다면 내년 초 이후 경정청구가 가능할 것으로 추정(국세청 Q&A의 "7월경 오픈" 시기 패턴 기준).
- 5,500만 원 구간은 종합소득금액 4,500만 원 조건이 같이 붙으므로 근로소득만 있으면 총급여 기준만 보면 된다고 추정.
- 정부안(한도 1,200만 원·청년 17% 특례)은 연말까지 국회 결과가 나올 수 있어, 발행 당일 최신 확인 필요하다고 추정.
