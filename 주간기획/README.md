# 주간기획
- 사람이 보는 파일만 복사해 모은 폴더입니다. 원본은 옮기거나 지우지 않습니다.
- 구조: `주간기획/<주 시작일>/` 안에 확정목록.md, 글쓰기방향-<MMDD>주.md, products_<날짜>.txt, 원고/(글 1편당 파일 1개).
- 매주 새 주 폴더(예: 2026-11-23)를 새로 만들어 같은 방식으로 채웁니다.
- 도구가 읽고 쓰는 원본은 계속 `pipeline/final/` 에 있습니다. 여기 파일을 고쳐도 도구에는 반영되지 않습니다.
- 원고 파일은 글쓰기 지시 + 확정 제목 + 본문 설계 + 쓰는 방향 + 경험 칸 + 제품 링크 순서입니다.
