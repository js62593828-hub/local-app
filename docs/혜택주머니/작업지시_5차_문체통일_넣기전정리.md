## 사용자 결정 (11/19 오후)
- **본문은 모든 글 격식체(-습니다/-입니다).** 해요체는 도입 공감 질문·마치며 인사 같은 곳에 몇 마디만(본문 문장 끝의 20% 이하). 글마다 톤 고르기·묶음 안 톤 번갈아 쓰기는 없앤다. 제목은 이 규칙에서 뺀다(제목클릭규칙대로).
- 본문(코드 블록 A·B) 안에 "[확인 필요]" 같은 표시를 글자로 남기지 않는다. 확인 안 된 숫자·날짜는 문장째 빼거나 단정하지 않는 문장으로. 공식 확인 안 된 계산값은 쓰지 않는다.
- 3번 제목 → **월세 세액공제 조건, 총급여 5,500만 원 이하면 17%예요**

## 3. 11/23 주 원고 14편 고치기 (hyetaek-writer, 한 번에 3~4명)
글마다 넘길 지시:
- 본문을 격식체로 바꾼다(내용·사실·순서·소제목 뜻은 그대로). 해요체로 끝나는 소제목은 격식체나 명사형으로 바꾸고, 바뀐 소제목은 메모의 본문 이미지 alt 줄(`"## …" →`)과 출처 캡처 추천 소제목에도 글자 그대로 맞춘다. 메타 디스크립션 끝말도 격식체로.
- 본문의 [확인 필요]류 표시를 없애고, 확인 안 된 숫자·날짜 문장은 빼거나 단정하지 않는 문장으로. 1번 글의 체납 충당 계산 예시("95만 원 중 최대 28만 5천 원")처럼 공식 확인 안 된 계산값은 뺀다. 코드 블록 밖 [확인 필요] 메모는 그대로 둔다.
- 3번 글: 제목을 위 문구로 바꾸고, 도입부·표지 1줄/2줄·메타 디스크립션이 새 제목과 맞는지 맞춘다(17%는 총급여 5,500만 원 이하, 5,500만~8,000만 원은 15%).
- 제목은 3번 말고는 그대로 둔다.
- 고친 뒤 `lt_draft_check` 통과(글자 수 기준 아래로 떨어지면 사실 확인 메모에 있는 확인된 내용으로만 보충).
- 이미 격식체 위주이고 표시도 없는 글은 검사만 하고 넘어간다.
