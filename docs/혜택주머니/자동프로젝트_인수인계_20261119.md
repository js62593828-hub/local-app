## 1. 자동 프로젝트란
혜택주머니(info-labs.co.kr, 앱 채널 `longterm_wp`) 주간 작업을 Claude Code + 에고라이트로 자동화한 것.
- **사람이 하는 일**: 기획표 [확인] 1번 → 앱 입력 전 "넣어" → 최종본 화면에서 **API 발행 버튼**(예약) → 워드프레스 확인 → 색인 요청.
- **나머지는 자동**: 실적 분석 → 키워드 발굴 → 🎯 검색량 → 구글 경쟁 → 기획표 → 사실 확인 → 원고 14편 → 검사 → 앱 입력(키워드·원고·메타·이미지·최종본·예약일시).

1. 앱 폴더에서 Claude Code 실행(창 모델은 Sonnet 5.5로 충분 — 원고만 Opus).
2. `/hyetaek-weekly 11/30` 처럼 시작 → 기획표에서 멈춤.
3. [확인] 보내기:
```
[확인]
빼거나 바꿀 묶음·글: 없음
지역·대상 버전 선택: 기본안
```

5. 최종본 화면에서 **발행 시각 순서대로** API 발행(같은 묶음 내부링크가 먼저 예약된 글에만 걸리기 때문).
