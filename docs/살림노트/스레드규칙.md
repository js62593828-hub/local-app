# 스레드규칙 (N살림노트 · V2.0 · 2026-11-19)

> 목적: 블로그 원고 1편마다 스레드(Threads) 글 1개를 같이 만들어, 검색 노출과 상관없는 유입을 만든다.

## 1. 어느 원고에 만드나
| 스레드 계정 | 만드는 원고 | 링크 |
|---|---|---|
| 살림 계정 | **원고 전부**(A·B·C) | **C(숍글)만** 첫 답글에 쇼핑커넥트 링크 |

- 원고 1편 = 스레드 글 1개. 한 원고로 여러 개 쪼개지 않는다.

## 2. 출력 형식 (원고와 메모 다음, 맨 끝에)
```
[스레드]
계정: 살림
종류: 일반 / 링크
올릴 때: 블로그 발행 날 · 아침(07~09시) 또는 저녁(18~21시)
본문:
(본문 줄들 — 아래 3장)
답글:
(링크 글만. 일반 글은 "없음")
태그: (주제 태그 1개, # 없이)
사진: 표지 / 본문 n번째(소제목 이름) / 없음
```

## 3. 본문 쓰는 법
> 느낌: 정보 글이 아니라 **친구한테 "이거 봤어?" 하고 전해 주는 톡**. 블로그 문장보다 한 단계 가볍게.

1. **첫 줄 = 툭 던지는 질문이나 한마디.** 15~30자. 독자 상황을 콕 짚는 질문형을 1순위로.
   - 예: "수건 빨아도 쉰내 나는 집?" / "원룸 제습기, 용량부터 보고 있음?"
2. **가운데 2~4줄 = 들은 얘기 전하듯 핵심만.** 끝맺음은 "~라 함", "~없다고", "~라더라", "~래" 같은 전달 말투를 섞는다. 온도·시간·용량 같은 핵심 숫자는 그대로 넣는다(가격 숫자는 5장대로 금지).
   - 답을 숨기지 않는다. "답은 블로그에" 같은 낚시 금지.
   - 확실하지 않은 부분은 솔직하게: "~는 집마다 다르다고 함".
3. **끝에서 두 번째 줄 = 짧은 한 줄 조언.** "~부터 확인해 보시길", "~먼저 봐 봐".
4. **마지막 줄(선택) = 혼잣말 같은 감상 한 줄.** "이건 좀 귀찮긴 함 ㅠㅠ", "진작 알았으면 좋았을 걸"처럼 누구나 할 법한 공감형 감탄만. 구체적인 사용담("우리 집에 써 보니")은 5장 금지 그대로.
   - 링크 글이면 이 줄 대신 "제품은 첫 답글에".
5. 길이: 본문 **공백 포함 100~220자**(스레드 한 글 최대 500자). 한 줄에 한 문장, 줄 사이 빈 줄 없음.
6. 말투: **편한 반말 + 전달체.** 존댓말은 조언 줄에 "~하시길" 정도만 섞어도 됨. 딱딱한 설명체("~입니다", "~해야 합니다") 금지.
7. 이모지 0~1개. 대신 "ㅠㅠ", "......" 같은 글자 표현은 글 하나에 1번까지 허용. 해시태그는 본문에 쓰지 않고 `태그:` 칸에 1개만.
8. 같은 주의 스레드끼리 첫 줄·감상 줄이 겹치지 않게 한다.

## 4. 링크 글 (C 숍글)
- **계정을 만들고 첫 7일은 링크 금지**: 이 기간엔 숍글도 `종류: 일반`으로 쓰고 제품 줄을 뺀다.
- 본문 **첫 줄 맨 앞에 `(광고)`**를 붙인다(공정위: 글 중심 매체는 첫 부분 표시).
- 본문에는 제품명·링크를 넣지 않는다. 고르는 기준·이런 집에 맞는 것까지 본문에서 답한다.
- 답글 형식:
  ```
  이 글은 네이버 쇼핑커넥트 활동으로 판매 수수료를 받을 수 있어요.
  ○○ 고르는 기준에 맞춘 제품: (제품명)
  [구매링크]
  ```
  제품이 2개면 제품명·[구매링크]를 2줄씩. 원고의 제품 링크가 있으면 그 링크를 그대로 쓴다.
- 링크 글은 계정 전체 글의 1/3을 넘지 않게 한다(21편 중 C 6편 ≈ 29%).

## 4-1. 사진
- 새로 만들지 않는다. 그 글의 기존 사진 중 1장만 고른다.
- **사진 있음 / 텍스트만을 번갈아**(같은 날 아침 글 = 사진, 저녁 글 = 텍스트만) — 조회수로 기본값을 정한다.
- 고르는 순서: 숍글 = 표지(제목 글자가 박힌 것) / 일반글 = 본문 사진 중 장면이 가장 분명한 1장(글자 없음).
- 쇼핑몰 제품 사진·다른 사람 사진은 쓰지 않는다. 직접 찍은 우리 집 사진이 있으면 그게 1순위.
- `사진:` 칸에는 "표지" / "본문 n번째(소제목 이름)" / "없음" 중 하나를 적는다.

## 5. 금지 (블로그 규칙과 같음)
- 써 본 척("써 보니", "우리 집에 들였더니"), 가짜 인물·나이·직업 설정.
- 가격 숫자, 별점·리뷰 수 숫자.
- 다른 브랜드 깎아내리기, 효능·치료 주장, 공포 조장.
- 블로그 본문 문장을 그대로 옮겨 붙이기(새로 줄여 쓴다).

## 6. 예시 (이 말투를 따라 쓴다)
**일반(A 해결형)**
```
[스레드]
계정: 살림
종류: 일반
올릴 때: 블로그 발행 날 · 저녁
본문:
수건 빨아도 쉰내 나는 집?
세제 탓 아니고 거의 세탁조 곰팡이랑 덜 마른 채 개는 게 원인이래.
세탁조 클리너 한 번 돌리고, 수건만 따로 40도 이상으로.
섬유유연제는 빼고, 다 마르면 바로 개기.
이 세 개면 거의 잡힌다더라
답글: 없음
태그: 살림팁
사진: 없음
```
**링크(C 결정형, 7일 이후)**
```
[스레드]
계정: 살림
종류: 링크
올릴 때: 블로그 발행 날 · 아침
본문:
(광고) 원룸 제습기, 용량부터 보고 있음?
원룸은 하루 10L급이면 충분하다 함.
그보다 물통 크기랑 소음이 더 중요하다고.
자는 방에 둘 거면 저소음 모드 있는지부터 확인해 봐
제품은 첫 답글에
답글:
이 글은 네이버 쇼핑커넥트 활동으로 판매 수수료를 받을 수 있어요.
원룸·저소음 기준에 맞춘 제품: (제품명)
[구매링크]
태그: 제습기
사진: 표지
```
(예시 속 숫자는 모양만 보여 주는 것이다. 실제 숫자는 그 글 본문에 근거가 있는 것만.)
