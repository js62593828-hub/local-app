# 제목 클릭 규칙 (N살림노트 · V2.0 · 2026-11-19)

> 적용: 네이버 "우리집 살림노트"의 제목.
> - 확정 제목은 기획 도구(weekly_plan)가 만들고, 주간 검수 때 이 규칙으로 읽어 본다(검수기준서 5장 ⑤).
> - 원고에서는 확정 제목을 그대로 쓰고, 더 나은 안을 낼 때(대안 1개)·확정 제목이 없는 단건 요청·표지 1줄에 이 규칙을 쓴다.
> 나눠 맡는 것: 금지 규칙(키워드 글자 그대로·길이·가격 금지·"총정리" 금지·피할 표현)은 원고지침, 클릭 장치·배합·점수·최종 숙고는 이 파일.

## 1. 목표와 근거

목표 = 문제가 되지 않는 선 안에서 **클릭을 가장 많이 받는 제목**. 감이 아니라 실험으로 확인된 장치를 쓴다.

- Upworthy 실험(제목 약 10만 5천 개, 노출 약 3억 7천만 회): 부정적인 단어가 하나 늘 때마다 클릭률이 약 2.3% 오르고, 긍정적인 단어는 하나마다 약 1% 내려갔다. 감정으로는 **슬픔·아쉬움 계열은 올리고, 공포·기쁨 계열은 내렸다**.
- Outbrain 분석: "절대·최악" 같은 **부정 최상급**은 클릭률이 약 30% 높았고, "최고·완벽" 같은 **긍정 최상급**은 약 29% 낮았다.
- 구글 검색 결과 분석(Backlinko): **질문형 제목은 효과 차이가 거의 없었다.** 검색에서는 무엇을 주는지 분명한 제목이 이긴다.

→ 정리: "좋아요·최고예요" 같은 들뜬 칭찬보다 **구체적인 결과**가 더 눌린다. 겁주기(공포)는 오히려 덜 눌리고 위험하다. 물음표 자체는 무기가 아니다. **숫자·대상·반전으로 구체적으로** 만든다.

→ 위 실험은 뉴스 피드 제목이다. 검색하는 사람은 이미 문제를 겪고 있으므로, "부정적인 단어"보다 **"내 물건·내 돈·내 일정이 어떻게 되는지"를 눈에 보이게 말하는 것**이 더 잘 눌린다. 그래서 손실은 추상어(손해·피해·낭패)가 아니라 **결과를 동사로** 말한다(숨이 죽어요·뭉쳐요·누레져요·요금이 늘어요).

→ 부정 말은 **여러 장치 중 하나일 뿐**이다. 실험의 효과는 "자연스럽게 읽히는 제목" 안에서 나온 것이고, 억지로 끼운 부정 말은 오히려 낚시처럼 보여 덜 눌린다. **끌림(궁금함·내 얘기 같음·쉬워 보임)과 자연스러움이 먼저**, 부정 말은 그 글 내용에 실제로 손실·실수가 있을 때만 쓴다.

## 2. 클릭 장치 7가지

제목은 **장치 2개 이상**(3개면 더 좋다)을 한 문장 안에 자연스럽게 섞는다. **어느 장치든 필수는 없다**.

| 장치 | 무엇 | 말의 예 |
|---|---|---|
| A 손실·실수 | 하던 방법이 틀렸거나, 모르면 눈에 보이는 결과가 생김 | **결과 말(우선)**: 숨이 죽어요 / 뭉쳐요 / 누레져요 / 줄어들어요 / 물이 새요 / 다시 피어요 / 금방 망가져요 / 요금이 늘어요 · **실수 말**: 오히려 / 거꾸로 / 잘못 고르면 / 하지 마세요 / 놓치면 |
| B 구체 숫자 | 본문에 있는 숫자 1개 | 10분 / 60℃ / 3가지 / 물 반 컵 / 15일 |
| C 대상·상황 부르기 | "내 얘기다" 싶게 | 원룸이라면 / 드럼세탁기 쓰는 집 / 아이 있는 집 / 구스 패딩은 / 락스로도 안 빠질 때 |
| D 반전·오해 뒤집기 | 다들 아는 것이 틀림 | 다들 ~부터 하는데 순서가 반대예요 / ~가 원인이 아니었어요 |
| E 이유·정체 궁금증 | 답의 일부만 보여 줌 | ~하는 진짜 이유 / 범인은 ~였어요 |
| F 시간 압박(사실일 때만) | 실제 시즌 | 첫 한파 전에 / 김장 전에 |
| G 쉬운 해결 약속 | 노력은 작게, 결과는 크게 | 물 반 컵이면 / 휴지 한 장으로 / 10분이면 / 쓱 닦여요 / 한 번에 풀려요 |

- **결과 말은 그 글 본문(특히 도입 장면)에 나오는 말을 먼저 가져온다.** 나빠지는 결과(A)든 좋아지는 결과(G)든 같다. 예: 도입이 "작년보다 납작하고 숨이 죽은 느낌"이면 제목도 "숨이 죽어요".
- "손해·피해·낭패·문제·실패" 같은 추상어는 쓰지 않는다. 돈이 걸린 이야기(전기요금 등)는 "요금이 늘어요"처럼 결과로 말한다.
- **"헛수고·망쳐요·소용없어요"처럼 센 부정 말은 본문이 정말 그렇다고 말할 때만** 쓴다(예: 세제로 닦아도 어느 정도 닦이는데 "헛수고"라고 하면 부풀림).
- E를 쓰면 답은 본문 첫 3~4문장에서 바로 준다.
- 들뜬 긍정 단어(좋은·최고·완벽·꿀팁·대박·강추)는 넣지 않는다 — 효과가 낮다. **구체적으로 좋아지는 결과**(쓱 닦여요·냄새가 빠져요·10분이면 끝나요)는 들뜬 칭찬이 아니므로 써도 된다.

## 3. 유형별 배합 (추천)

| 유형 | 고정 조건 | 추천 배합 | 모양 예시 |
|---|---|---|---|
| A 해결형·B 점검형 | 키워드 글자 그대로 앞 15자 안, 25~35자 | A·D·G 중 1개 + B·C 중 1개 이상 | "전자레인지 청소 물 반 컵 5분 돌리면 찌든 때가 쓱 닦여요"(B+G) / "변기 막힘 뚫기 다들 뚫어뻥부터 쓰는데 순서가 반대예요"(D) |
| C 결정형(숍글) | 키워드 앞, 25~40자(30자 안팎 권장), 가격·할인율 없음, 고르는 표현 포함 | C(누구에게) + A·B·D 중 1개 | "패딩 세탁 세제 잘못 고르면 다운 충전재가 납작해져요"(A+C) / "온수매트 전기장판 비교, 원룸이라면 이것부터 보세요"(C+E) |

- 예시는 **모양**만 보여 준다. 숫자·사실은 그 글 본문에 있는 것만 쓴다.
- **한 주의 제목 중 A(손실·실수)가 들어간 것은 절반을 넘지 않게** 한다(부정 말 일색이면 블로그 전체가 겁주는 느낌이 난다).
- 표지 1줄도 같은 장치 중 1개(A·B·G 중)를 쓴다. 제목에 결과 말을 썼으면 표지에도 같은 결과 말을 쓴다.

## 4. 절대 넘지 않는 선

### 4-1. 문제가 되는 범위

1. **약속 = 본문.** 제목이 약속한 답은 첫 3~4문장에 있다. 본문에 없는 약속은 거짓 낚시다. 네이버는 낚시성 문서를 검색 스팸·어뷰징 유형으로 보고 노출을 막을 수 있다.
2. 제목 속 숫자·날짜·대상·**결과 말**은 본문에 있는 **사실만**. (예: "드라이 맡기면 숨이 죽어요"는 본문이 그 이유를 근거와 함께 설명할 때만)
3. 금지 단어: 충격·경악·소름·난리·역대급·무조건·100%·최고·1위·최저가·완벽·"클릭하세요" 류.
4. 금지 내용: 질병·사고·범죄로 겁주기, 연예·정치, 특정 업체·제품 깎아내리기.
5. C 결정형: 가격·할인율 금지, 제품을 써 본 척 금지(공정위 추천·보증 심사지침, 표시광고법 — 과장·오인 표현 금지).
6. 피할 표현 블록(번역투·AI 말투)은 제목에도 그대로.

### 4-2. 읽기 검사 (하나라도 걸리면 후보에서 뺀다)

클릭 장치를 다 넣어도 읽기 어색하면 눌리지 않는다. 후보마다 소리 내어 읽고 아래 5가지를 본다.

1. **키워드가 문장과 이어지는가**: 키워드 바로 뒤에는 ① 조사(은·는·을·를·로·에) ② 쉼표 ③ 이어 주는 말("잘못 고르면", "고를 때", "고르는 기준", "~하면") 중 하나가 온다. **키워드 뒤에 다른 명사 덩어리를 바로 붙이지 않는다.**
   - ✗ "패딩 세탁 세제 구스 패딩은 …" (키워드 뒤에 명사가 바로 옴)
   - ○ "패딩 세탁 세제 잘못 고르면 …" / "패딩 세탁 세제, 다운 전용이 아니면 …"
2. **같은 단어가 두 번 나오지 않는가**: 키워드에 든 단어도 센다. (✗ 패딩·패딩, 세제·세제) 대상을 다시 부르고 싶으면 다른 말로 바꾼다(구스 패딩 → 충전재·다운).
3. **명사 토막 두 개를 쉼표로 잇지 않았는가**: 쉼표 앞뒤가 둘 다 명사(손해·고르기·비교·방법)로 끝나면 문장이 끝나지 않은 느낌이 난다. 둘 중 하나, 되도록 **뒤 토막은 말(~요·~다)로 끝낸다.** 검색형 꼬리("~고르는 기준", "~ 3가지")는 쉼표 없이 쓰거나, 앞 토막을 말로 끝낸다.
   - ✗ "…드라이하면 손해, 다운 전용 세제 고르기"
4. **쉼표 앞뒤 길이가 맞는가**: 쉼표를 쓰면 앞뒤 토막 중 긴 쪽이 짧은 쪽의 **2배를 넘지 않게**(띄어쓰기 빼고 글자 수로). 쉼표 없이 한 문장으로 자연스러우면 쉼표를 쓰지 않는 쪽이 낫다.
5. **말로 할 수 있는 문장인가**: 이웃에게 그대로 말해도 어색하지 않은지 본다. 말을 줄여 쓴 형태("드라이하면" → "드라이 맡기면"), 조사가 빠진 나열은 고친다.

## 5. 고르는 법 — 클릭 점수

후보마다 먼저 **4-1 금지선과 4-2 읽기 검사**를 본다. 하나라도 걸리면 0점(후보에서 뺀다). 통과한 후보만 점수를 매기고 가장 높은 것을 후보로 한다(같으면 더 자연스럽게 읽히는 쪽, 그다음 더 짧은 쪽). 후보는 반드시 **5-2 최종 숙고**를 거쳐 최종 제목이 된다.

- 장치 하나당 +1(최대 3)
- 키워드가 앞 15자 안에 글자 그대로 +1
- 길이 +1: **25~35자**(C는 40자까지 허용하지만 36~40자는 가점 없음)
- **결과 말 +1**: 본문에 나오는 구체적인 결과를 말로 썼을 때. **나빠지는 결과**(숨이 죽어요·누레져요)든 **좋아지는 결과**(쓱 닦여요·냄새가 빠져요·10분이면 끝나요)든 인정한다. "손해·피해·낭패·문제", "좋아요·최고예요"처럼 흐린 말은 결과 말로 치지 않는다.

**후보는 5점 이상만.** 5점이 안 나오면 장치를 바꿔 다시 만든다. 점수를 맞추려고 장치를 억지로 끼워 넣지 않는다 — 어색해지면 읽기 검사나 최종 숙고에서 빠진다.

같은 주에 **같은 장치 조합 3편 이상** 금지(기계적으로 보인다). 같은 주에 **같은 결과 말을 3편 이상** 쓰지 않는다.

### 5-2. 최종 숙고 (후보마다 반드시)

점수는 "장치가 들어 있는가"만 센다. 실제로 눌리는지는 따로 따져 봐야 한다. 후보를 **검색 결과에 다른 블로그 제목 9개와 함께 떠 있다고 생각하고** 아래 5가지를 묻는다.

1. **충분히 끌리는가**: 제목만 보고 "눌러 봐야겠다"가 드는가?
   - 약한 신호: 제목만 읽어도 답을 다 알 수 있음(궁금한 게 없음) / 흔한 설명문("○○ 방법 정리")과 다를 게 없음 / 내 상황이라는 느낌이 없음.
   - 고치는 방향: 답의 일부만 보여 주기(E), 대상을 좁혀 부르기(C), 뜻밖의 사실 앞세우기(D), 숫자로 구체화(B), "이것만 하면 된다"(G).
2. **어색하거나 잘 안 쓰는 말이 없는가**: 이웃이 실제로 쓰는 말인가?
   - 걸리는 말: 한자어·딱딱한 말(번식·가속화·발생·방치·유발·숙지), 번역투, 전문 용어(사람들이 검색창에 쓰지 않는 말), 억지로 만든 말.
   - 고치는 방향: 쉬운 말로(번식이 가속화돼요 → 금방 번져요, 방치하면 → 그냥 두면). 키워드는 글자 그대로 둔다.
3. **부정 말이 억지는 아닌가**: 부정 말(A)이 본문 내용보다 세게 들리거나, 굳이 부정일 필요가 없는데 끼워 넣었는가? 한 제목에 부정 말이 두 번 나오는가?
   - 고치는 방향: 부정 말을 빼고 **쉬운 해결(G)·숫자(B)·대상(C)**으로 바꾼다. 부정이 내용의 핵심이면 하나만 남긴다.
4. **3초 안에 무슨 글인지 알 수 있는가**: 장치를 많이 넣다가 뜻이 흐려지지 않았는가?
5. **약속을 본문이 지키는가**: 고친 제목의 숫자·결과 말·대상이 본문 첫 3~4문장에 있는가?

**고치는 법**
- 5가지가 모두 괜찮으면 그대로 최종 제목.
- 하나라도 걸리면 **고친다.** 키워드 글자 그대로·키워드 위치·길이·금지 단어는 그대로 지키고, 고친 제목은 4-1·4-2를 다시 통과해야 한다.
- 고친 제목은 **4점 이상이면 최종 제목으로 쓸 수 있다**(자연스러움·끌림이 점수보다 우선 — 장치 2개 + 키워드·길이면 4점). 고친 제목이 처음 후보보다 덜 끌리면 처음 것을 다시 고치거나 2위 후보로 같은 과정을 밟는다.
- 고치기는 **최대 2번**. 2번 고쳐도 걸리면 가장 나은 것을 쓰고 ⚠ "제목 확인 필요(이유 한 줄)"를 남긴다.

**출력** (대안 제목·단건 제목을 낼 때 그 아래 한 줄)
- 그대로일 때: "제목 이유: 장치 B+G · 5점 · 읽기 검사 ✔ · 최종 숙고 ✔ 그대로 · 겨냥한 의도 한 줄"
- 고쳤을 때: "제목 이유: 장치 C+G · 4점 · 읽기 검사 ✔ · 최종 숙고 ✔ 고침(처음: ○○○ → 걸린 곳: 2번 '번식 가속화' 딱딱함) · 겨냥한 의도 한 줄"
- 대안 제목을 냈거나 사용자가 제목을 바꿨으면 "이번 주 기록 저장"의 바꾼 제목 칸에 장치도 함께 남긴다.

### 5-3. 고치기 예

| 처음 | 걸린 곳 | 고친 제목 | 점수 |
|---|---|---|---|
| 패딩 세탁 세제 구스 패딩은 드라이하면 손해, 다운 전용 세제 고르기 | 읽기 검사 1·2·3·4 + 추상어 "손해" | **패딩 세탁 세제 잘못 고르면 다운 충전재가 납작해져요**(결과 말 = 도입의 "납작하고") | A+C 2 + 키워드 앞 1 + 길이 1 + 결과 말 1 = 5 |
| 전자레인지 청소 세제로 닦으면 헛수고, 물 반 컵이면 돼요 | 숙고 3: "헛수고"가 부풀림(세제로도 어느 정도 닦임), 억지 부정 | **전자레인지 청소 물 반 컵 5분 돌리면 찌든 때가 쓱 닦여요** | B+G 2 + 키워드 앞 1 + 길이 1 + 결과 말(좋아지는 결과) 1 = 5 |
| 결로 방지 방법 창틀 물방울 방치하면 곰팡이 번식 가속화돼요 | 숙고 2: "방치·번식·가속화" 딱딱한 한자어 | **결로 방지 방법, 창틀 물기 그냥 두면 곰팡이가 금방 번져요** | A+C 2 + 키워드 앞 1 + 길이 1 + 결과 말 1 = 5 |
| 욕실 실리콘 곰팡이 락스 뿌리면 헛수고, 또 피어요 | 숙고 3: 부정 말 두 번, 겁주는 느낌 / 숙고 1: 해결이 안 보여 끌림 약함 | **욕실 실리콘 곰팡이 락스로도 안 빠질 땐 휴지 한 장이면 돼요** | C+G 2 + 키워드 앞 1 + 길이 1 = 4 (숙고로 고친 제목이라 사용 가능) |

(예시 속 사실은 모양만 보여 주는 것이다. 실제 제목의 숫자·결과 말은 그 글 본문에 있어야 한다.)

## 6. 성과 확인

네이버 통계(perf_inbox)의 글별 조회수를 4주 단위로 보고, 잘 눌린 장치 조합을 다음 판에서 기본으로 올린다. 결과 말을 쓴 제목과 안 쓴 제목, A(부정)가 든 제목과 없는 제목도 함께 비교한다. 표본 수를 함께 적고 10편 미만으로 단정하지 않는다.
